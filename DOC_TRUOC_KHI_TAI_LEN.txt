GIAO DIỆN BẢN WEB — Mô phỏng chạy tàu ĐSĐT 3.24.0
Đẩy TOÀN BỘ nội dung thư mục này lên GỐC nhánh main của kho https://github.com/lehtung/Metro_Simulation

Cách 1 — trên github.com: Add file → Upload files → kéo thả tất cả (giữ nguyên thư mục css/, js/, js/khung/) → Commit changes.
  Lưu ý: trình duyệt không kéo được tệp ẩn .nojekyll. Sau khi tải lên, bấm "Add file → Create new file",
  gõ tên tệp là  .nojekyll  rồi để trống nội dung và Commit. (Tệp này báo GitHub Pages không xử lý qua Jekyll.)
Cách 2 — bằng git:
  git clone https://github.com/lehtung/Metro_Simulation.git
  (chép toàn bộ nội dung thư mục này vào thư mục kho, kể cả .nojekyll)
  cd Metro_Simulation && git add -A && git commit -m "Ban web 3.24.0" && git push

Sau đó: kho → Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.
1–2 phút sau mở https://lehtung.github.io/Metro_Simulation/
